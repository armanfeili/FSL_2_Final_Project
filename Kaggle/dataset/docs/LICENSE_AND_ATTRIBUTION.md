# License and attribution

## Authorship of this processed table

The processed analysis table (`processed_who_tb_treatment_success_country_year_2012_2023.csv`) and the
accompanying documentation in this Kaggle package were created by
**Arman Feili** by joining, filtering, and standardizing public WHO
Global Tuberculosis Programme files. The processing code is part of an
academic project (Bayesian beta-binomial modeling of TB treatment
success) and is not affiliated with WHO.

## Original data source

Original data source: **World Health Organization (WHO) Global
Tuberculosis Programme**, public TB data portal at
<https://www.who.int/teams/global-tuberculosis-programme/data>.

Users should follow WHO's data-use and attribution terms when reusing
this derivative. WHO and the contributing national TB programmes that
produced the underlying data **should be acknowledged** in any reuse,
and this expectation is inherited by this derivative dataset.
